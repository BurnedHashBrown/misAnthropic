# Filtr. project context

Filtr. is a safety-first early-warning web app for social-media conversations. It is designed for a young person who may be groomed, romance scammed, or pressured into sending money or intimate content.

The central product principle is restraint: long distance, warmth, frequent messages, and romance are not enough to trigger a warning. Filtr. waits for pattern escalation such as secrecy, urgency, isolation, financial requests, private-image pressure, or blackmail.

This repository is currently a dependency-free static web app. It can be hosted on GitHub Pages, Netlify, Vercel static hosting, or any standard web host. Live Watch is represented as a product prototype; a production browser extension and secure backend are separate work.

## Pages

- `index.html`: Home and Live Watch dashboard
- `live-watch.html`: Live Watch browser extension explanation and downloads (Microsoft Edge Store & GitHub .ZIP)
- `review.html`: manual Paste Review tool
- `timeline.html`: explains risk escalation
- `help.html`: sextortion and grooming next steps
- `guides.html`: users, parents, and trusted-friend education
- `privacy.html`: product privacy commitments
- `about.html`: mission and rationale
- `terms.html`: safety and prototype disclaimer
- `signup.html` and `login.html`: account entry screens, demo-only

## Safety boundary

The app is a safety aid. It does not determine intent, perform law-enforcement work, provide therapy, or replace emergency services. A production release needs safeguarding, legal, security, privacy, accessibility, and user-research review.
